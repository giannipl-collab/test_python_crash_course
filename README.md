## Descrizione del Progetto
Questo repository contiene l'elaborato finale svolto durante il corso "Python Crash Course". Il progetto si focalizza sull'applicazione della programmazione orientata agli oggetti (OOP), seguendo i principi e le dispense fornite a lezione.

## Struttura dei File
Il repository è organizzato come segue:

* **`student_pro.py`**: Script principale che implementa la classe `Studente`. Include metodi avanzati per:
    - Gestione del profilo studente (costruttore e metodi d'istanza).
    - Gestione del libretto voti con **validazione dei dati** (range 18-30).
    - Calcolo automatico della media accademica.
    - Valutazione della preparazione in base alle ore di studio effettuate.

## Competenze Acquisite
Attraverso questo script sono stati messi in pratica i seguenti concetti trattati nel corso:
1. **Fondamenti**: Gestione di liste, logica condizionale e f-strings per l'output formattato.
2. **OOP (Object Oriented Programming)**: Creazione di classi, costruttori (`__init__`), incapsulamento della logica nei metodi e utilizzo di metodi speciali (`__str__`).
3. **Versionamento**: Utilizzo di GitHub per la gestione del codice e della documentazione del progetto.
