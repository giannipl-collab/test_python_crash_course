## Descrizione del Progetto
Questo repository contiene gli esercizi svolti durante il corso "Python Crash Course". Il progetto si focalizza sull'applicazione della programmazione orientata agli oggetti (OOP) e sull'analisi dei dati tramite la libreria Pandas, seguendo le dispense e i notebook forniti a lezione.

## Struttura dei File
Il repository è organizzato come segue:

* **`student_pro.py`**: Script principale che implementa la classe `Studente`. Include metodi per la presentazione del profilo, la gestione del libretto voti (con validazione del range 18-30), il calcolo della media accademica e la valutazione della preparazione in base alle ore di studio.
* **`classExample.py`**: Esempio di analisi dati professionale che utilizza il paradigma OOP per elaborare informazioni su vendite e ricavi, dimostrando l'uso di Pandas e del *method chaining*.
* **`data_1.csv`**: Dataset di esempio in formato CSV utilizzato dagli script per simulare il caricamento e la pulizia dei dati.

## Competenze Acquisite
Attraverso questi script sono stati messi in pratica i seguenti concetti trattati nel corso:
1.  **Fondamenti**: Gestione di liste, cicli for e f-strings per l'output formattato.
2.  **OOP**: Creazione di classi, costruttori (`__init__`), metodi d'istanza e metodi speciali (`__str__`).
3.  **Data Analysis**: Utilizzo di Pandas per il caricamento (`read_csv`), la pulizia (`dropna`, `to_datetime`) e l'aggregazione dei dati (`groupby`).
4.  **Versionamento**: Utilizzo di Git e GitHub per la gestione del codice e la documentazione del progetto.
